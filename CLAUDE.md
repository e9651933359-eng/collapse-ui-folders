# Collapse Chat UI — контекст для Claude Code

## Цель проекта

React-прототип чатов Collapse с папками, Message Editor, локальным UI Kit и федеративными сценариями. Обычные чаты и Федерация используют одно ядро компонентов и токенов.

## Источник компонентов

Компоненты, токены, стили и композиции чатов приходят из пакета `@collapse/ui`: единственный источник — репозиторий `e9651933359-eng/collapse-ui-storybook` и его Storybook. В этом репозитории лежат только вход приложения (`src/main.tsx`), экран приложения (`src/App.tsx`) и конфигурация сборки.

- Не копируй и не правь компоненты здесь. Нужна правка компонента или токена — делай её в репозитории Storybook и обнови версию пакета.
- Документация дизайн-системы поставляется с пакетом: `node_modules/@collapse/ui/docs/design-system/` (CORE.md, BASE.md, COMPONENT_INVENTORY.md, FEDERATION.md и др.). Читай её вместо `docs/design-system/` из пунктов ниже.
- Иллюстрации и фото библиотеки копируются в `public/assets` плагином `@collapse/ui/vite` при запуске и сборке; в git они не хранятся.
- Пути `src/components`, `src/features`, `src/theme`, `src/types` и команды Storybook ниже относятся к репозиторию Storybook.
- Обновить библиотеку: `npm update @collapse/ui`, затем `npm run build`.

## Перед началом работы

1. Выполни `git status` и не перезаписывай чужие незакоммиченные изменения.
2. Подтяни актуальную ветку с GitHub только если рабочая копия чистая либо изменения пользователя сохранены.
3. Перед любыми изменениями UI полностью прочитай:
   - `AGENTS.md`;
   - `DESIGN.md`;
   - `docs/design-system/CORE.md`;
   - `docs/design-system/BASE.md`;
   - документацию изменяемой группы компонентов.
4. Для федеративных сценариев дополнительно прочитай `docs/design-system/FEDERATION.md`.

## Архитектура UI Kit

- `src/theme/core/` — Core-токены: цвета, размеры, типографика, эффекты, анимация и layout.
- `src/theme/tokens.css` — совместимые aliases токенов.
- `src/components/ui/` — базовые компоненты Collapse и их Storybook stories.
- `src/components/feedback/` — Toast, SnackBar, Popover, Tooltip и другие feedback-компоненты.
- `src/components/option-menu/` — меню и DropField.
- `src/components/shell/` — общая оболочка: ProductRail и ChatList.
- `src/features/chat/` — продуктовые композиции чатов, сообщений и Message Editor.
- `src/features/federation/` — только федеративная логика, данные и композиции.
- `src/types/` — общие типы продукта.
- `docs/design-system/` — правила и инвентаризация дизайн-системы.

Публичные экспорты UI Kit находятся в `src/components/ui/index.ts`.

## Главные правила

- Используй существующие компоненты и CSS-переменные `--collapse-*`.
- Не копируй размеры, отступы, радиусы, границы и состояния в экранные стили.
- Общую визуальную правку делай в token/component layer, затем проверяй все места использования.
- Абсолютные размеры разрешены только в файлах токенов и должны иметь указанный источник.
- Новое или изменённое состояние компонента обязательно добавляй в Storybook.
- Вместе с кодом обновляй соответствующий документ в `docs/design-system/`.
- Если Figma недоступна, явно пометь решение как техническое допущение.
- Не меняй обычные чаты ради Федерации: федеративные возможности подключаются необязательными props/slots и по умолчанию выключены.
- Не размещай продуктовые данные и правила Федерации внутри базовых UI-компонентов.
- Сохраняй доступность: клавиатура, `focus-visible`, Escape, aria-атрибуты и reduced motion.

## Маршруты и сборки

- `/chats` — обычные чаты.
- `/federation` — федеративный сценарий на том же ядре.
- `npm run dev` — локальный запуск.
- `npm run build` — проверка TypeScript и сборка обычных чатов.
- `npm run build:federation` — сборка федеративного варианта.
- `npm run storybook` — локальный Storybook.
- `npm run build-storybook` — проверка Storybook.

Перед завершением задачи выполни минимум `npm run build` и `npm run build-storybook`. Для изменений Федерации также выполни `npm run build:federation`.
