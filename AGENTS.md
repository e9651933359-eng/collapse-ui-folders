# AGENTS.md

Перед любыми изменениями UI:

1. Прочитать `DESIGN.md`, `docs/design-system/CORE.md`, `docs/design-system/BASE.md` и документацию изменяемой группы компонентов.
2. Использовать существующие токены Collapse и общие компоненты.
3. Не дублировать стили на уровне экрана; исправлять источник истины в token/component layer.
4. Если Figma-данные недоступны, явно отметить допущение и не выдавать его за правило Collapse.
5. Обновлять документацию и Storybook вместе с кодом.
6. Размеры, отступы, радиусы и границы компонентов брать из `--collapse-*`; абсолютные значения разрешены только внутри файла токенов с указанием источника.

## Публикация

- По умолчанию собирать, проверять и сохранять изменения в отдельной локальной ветке и коммите.
- Не выполнять `git push` и не обновлять GitHub Pages без явной просьбы пользователя опубликовать изменения.

Отвечай кратко и простым языком.
