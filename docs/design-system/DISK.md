# Файлы из МТС Диска в чатах (сценарии Teams)

Источник: [Figma, страница «Last», секции «Прямая ссылка на документ», «Документ с локального устройства», «Сценарии ошибок», «Отправка ссылки без прав», «Прикрепление с Диска»](https://www.figma.com/design/XjoKr5oZ1vXrB2TuYY7ydZ/?node-id=40000090-27622).

Компоненты макетов привязаны к дубликату дизайн-системы. Они не переносились: каждый сопоставлен с компонентом Collapse (таблица ниже), расхождения — технические допущения.

Права и доступы в чате не проверяются и не выдаются: это делает сам Диск. Функциональность включена во всех чатах, включая `/chats` и `/federation`: это осознанное решение владельца проекта, единственное исключение из правила «обычные чаты не меняются». Продуктовая логика лежит в `src/features/disk/`, базовые компоненты получили только необязательные props.

## Три сценария

| Сценарий | Как воспроизвести | Реализация |
|---|---|---|
| 1. Ссылка на документ | Вставить `https://disk.mts.ru/f/f1` или любую ссылку на `.pdf`, `.doc(x)`, `.xls(x)`, `.ppt(x)` в поле сообщения | Компактная карточка в редакторе (`ListItemFile`); после отправки баннер-карточка `FileCard` (миниатюра-заглушка, иконка типа, папка/домен, меню «Скопировать ссылку» / «Убрать предпросмотр»). Остальные ссылки остаются текстом |
| 2. Файл с Диска | Кнопка папки в тулбаре → «Выберите файлы» → «Прикрепить» | `DiskPickerModal` (`ModalPage`, `SearchField`, `Tabs type="line"`, список с CheckBox, сортировка, навигация по папкам и общим дискам, «N из 10»); в сообщении строка файла с меню «Скопировать ссылку» / «Удалить из чата» |
| 3. Локальный файл → Диск | Скрепка или drag-and-drop | `simulateUpload`: прогресс, ошибки, повтор; тост «Файл загружен на Диск» |

## Карточки в отправленном сообщении

- Отправленный файл с Диска или локальный (после загрузки на Диск) в форматах doc/docx, xls/xlsx, ppt/pptx, pdf показывается карточкой с миниатюрой (`FileCard` + `FilePreviewStub`, то же, что у ссылок на документы). Остальные типы и папки остаются строкой `ListItemFile`. До отправки, в редакторе, — всегда компактная строка.
- Допущение: узел Figma `40000116:35852` недоступен через MCP, карточка собрана по `8678:102365`.

## Ширина ленты сообщений

- Колонка сообщений (`message-feed__content`) ограничена `--collapse-size-message-editor-max` и выровнена с Message Editor по обоим краям; боковые отступы ленты и подложки редактора одинаковы (`--collapse-spacing-horizontal-l`). Источник: Figma `6932:40607`.

## Права и corner cases

| Ситуация | Демо-триггер | Поведение |
|---|---|---|
| Размер превышает лимит | файл >100 МБ | «Файл слишком большой», только корзина |
| Нет места на Диске | файл 50–100 МБ | «Недостаточно места» |
| Запрещённый тип | `.exe`, `.bat`, `.cmd`, `.msi`, `.scr` | «Формат не поддерживается», иконка с тегом `unk` |
| Обрыв связи | «network» или «сеть» в имени | авто-повтор через 2, 5 и 10 с («Повторная попытка N из 3…»), затем «Не удалось загрузить» с кнопками «Повторить» и корзиной; ручной повтор проходит |
| Локальный файл удалён или недоступен | «gone» или «удал» в имени (в браузере настоящее удаление не воспроизвести) | «Файл недоступен», только корзина |
| Успешная загрузка или прикрепление | любой обычный файл | вместо размера — иконка папки и «Файл на МТС Диске» (в макете подпись — домен `disk.mts-link.ru`, по решению владельца текст заменён) |
| Нет прав у отправителя | ссылка `https://disk.mts.ru/f/x1` | карточка «Нет доступа к файлу»; клик открывает модалку «Открывается Диск, где проверяются права и доступы»: права проверяет сам Диск, запрос доступа в чате не реализуется |
| Неизвестный тип на Диске | «Скрипт выгрузки.xyz» | иконка с тегом `xyz` |
| Внешняя ссылка | любой другой `https://…` | карточка с доменом |
| Удаление из чата | меню файла → «Удалить из чата» | `ConfirmDialog` «Файл исчезнет из этого чата, но останется доступен на Диске» |

## Допущения и что не сделано

- Домен `https://disk.mts.ru`, лимиты (100 МБ, свободная квота 50 МБ, до 10 файлов за раз) и список запрещённых расширений — демо-значения, ждут продуктовых.
- Мок Диска — `mockDisk.ts`; права и квота не приходят с сервера.
- Не реализованы: hover-popover с превью в сетке карточек, карточка-папка (в ДС макетов пропущена), ошибка «Не удалось выдать доступ» (права пока не трогаем), условие «Диск не приобретён».
- Экран запроса роли «Читатель» из макетов заменён по решению владельца на модалку перехода на Диск.
- Миниатюра в баннере — заглушка (`FilePreviewStub`), настоящее содержимое не рендерится. Кадр `40000106:45674` с макетом сообщения MCP не отдаёт («не найден»): карточка собрана по компоненту `8678:102365`.
- Правило «превью ссылки — одно на сообщение» принято как допущение.

- Вид списка выбора файлов собран по замечаниям владельца, а не по кадру Figma: узел `40000106:46488` MCP не отдаёт («не найден»). Отступы, типографику и ховер нужно сверить с макетом.
- Владелец всегда «Фамилия Имя», в том числе текущий пользователь (демо: «Соколов Вячеслав»).

## Ссылки МТС Линк (допущение прототипа)

Ссылки на хосты `mts-link.ru` / `*.mts-link.ru` разбираются по первому сегменту пути: `/docs/<id>` → docx, `/sheets/<id>` → xlsx, `/slides/<id>` → pptx (последнее — предположение). Другие пути не дают карточки. Название в баннере — мок по хэшу id, настоящее не запрашивается; в подписи — хост и иконка ссылки. Правило в `resolveLink` (`mockDisk.ts`).

## Сверка типографики карточек вложений (6150:24305)

`ListItemFile` теперь задаёт название по Paragraph/S/Regular (15/20, 0.12 px, 400), подпись по Caption/M/Regular (12/18, 0.15 px, 400, цвет `text/solid/base/tertiary`), как в макете; раньше не хватало letter-spacing, а подпись брала opacity-цвет. Размеры совпали с макетом без правок: строка 48 px, отступы 6 / 10, gap 16, скругление 18, иконка 40. Тот же набор применён к строке `FileCard`.

## Навигация по Диску в пикере и папки

Логика переходов взята из прототипа `Пикер файлов для чатов.html`:
- **Табы:** «Мой диск», «Доступные мне», «Избранное», «Недавние», «Общие диски» — `Tabs type="line"` (Figma my-Base 14589:3328, Type=Default). Выбор живёт между табами и папками.
- **Папка / диск:** двойной клик или Enter открывает; одиночный клик и Space выбирают. Папка — один объект, не её содержимое. Диск выбрать нельзя.
- **Путь:** внутри папки вместо табов стоит путь «Мой диск › … › Чаты › Макеты» (после третьего уровня схлопывается в корень › … › два последних); клик по звену поднимает на уровень. Корень свой у каждого раздела: «Мой диск» или «Общие диски».
- **Из плоских табов, поиска и «Выбранных»** заход в папку переключает на дерево («Мой диск» или «Общие диски», если объект лежит на диске) и закрывает поиск.
- **Общие диски:** корень — список дисков в одной колонке «Название» (серый круг с иконкой диска, без чекбокса, владельца и даты; сортировка только по названию, по умолчанию А→Я). Внутри диска всё как в «Моём диске».
- **Выбранные:** клик по счётчику «N из 10» показывает список выбранного со всех табов и папок (стрелка «Назад» и заголовок вместо табов); состав снимается при входе и не перестраивается при снятии галочек.
- **Поиск:** глобальный по всему Диску (файлы и папки, диски не попадают в выдачу), на время поиска вместо табов заголовок «Результаты поиска»; пусто — «Ничего не найдено».
- **Пустые состояния:** «В этой папке пусто», «Общих дисков нет», «Ничего не выбрано».
- **Прикрепление папки:** строка и карточка вложения с иконкой папки (`FileTypeIcon extension="folder"`, Figma 8734:83895), подпись «Папка на МТС Диске»; ссылка вида `/folders/<id>`. Ссылка на папку, вставленная в поле сообщения, карточки пока не даёт.

Допущения: данные Диска — мок (`mockDisk.ts`); в Figma нет макета пикера с навигацией, визуальные размеры пути, пустых состояний и кружка диска — технические допущения на токенах Base. Название типа табов: в коде `line` (в Figma этот вариант назван Default), потому что `default` в коде уже занят табами-плашками.

## Локальная папка (допущения прототипа)

Папку можно прикрепить с устройства: скрепка открывает меню «Файл» / «Папку» (в макетах меню нет — техническое допущение), либо папку перетаскивают в редактор. Папка уходит в чат **одним объектом** с иконкой папки, как и папка с Диска. Загрузка имитируется целиком по суммарному размеру; проверки по сумме: запрещённый формат внутри → «Формат не поддерживается», больше 100 МБ → «Файл слишком большой», больше свободной квоты → «Недостаточно места», в названии `network`/`сеть` → обрыв с авто-повтором, `gone`/`удал` → «Файл недоступен». Тексты ошибок общие с файлами, отдельных формулировок для папок в макетах нет. Пустая папка не прикрепляется. Логика: `localFolder.ts`, `upload.ts`.
